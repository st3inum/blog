This problem was from `SUST IUPC 2015`, problem `B`. Later it was added to UVa as `13035 - Another Combination Problem`. Full problemset can be found here: [SUST IUPC 2015 - UVa contest 360](https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=13&page=show_contest&contest=360)

## Problem:

There are $N$ boxes. Box $i$ has $i+1$ distinguishable balls.

Choose one box and pick two balls from it: one for left hand, one for right hand. Since left/right hand matters, order matters. Find total number of ways modulo $1000000007$.

{{< spoiler text="<b>Constraints</b>" >}}

- $1\le T\le 10^5$
- $1\le N\le 10^9$

{{< /spoiler >}}

## Solution:

For box $i$, there are $i+1$ balls.

If we take two balls and hands are different, then order matters.

So for box $i$:

$$
^{i+1}P_2 = (i+1)\times i
$$

Hence total answer:

\begin{align}
\text{ans} &= \sum_{i=1}^{n}{i(i+1)} \newline
&= \sum_{i=1}^{n}{(i^2+i)} \newline
&= \sum_{i=1}^{n}{i^2} + \sum_{i=1}^{n}{i} \newline
&= \frac{n(n+1)(2n+1)}{6} + \frac{n(n+1)}{2} \newline
&= \frac{n(n+1)(2n+1)}{6} + \frac{3n(n+1)}{6} \newline
&= \frac{n(n+1)(2n+4)}{6} \newline
&= \frac{n(n+1)(n+2)}{3}
\end{align}

Now, $n,n+1,n+2$ are $3$ consecutive numbers.

By pigeonhole principle, one of them must be divisible by $3$.

So we divide that number by $3$ first, then multiply the three numbers modulo $1000000007$.

$$
\text{ans} = \frac{n(n+1)(n+2)}{3}
$$
